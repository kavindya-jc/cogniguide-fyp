# CogniGuide backend

The server for the CogniGuide app: a Socratic maths coach for Grades 8–11 that asks questions
instead of giving answers. This Space only runs the API that the phone app talks to; it has no page
to look at. Check it works at `/health`.

Part of a final-year research project. Students use anonymous usernames only.
